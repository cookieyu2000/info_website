# Info Website

Personal portfolio website built with Create React App.

## Live Site

https://cookieyu2000.github.io/info_website

## Local Development

```bash
npm install
npm start
```

Open http://localhost:3000

## Local CMS (Decap)

Run these three commands in separate terminals:

```bash
# A
ç
# B
npx decap-server

# C
npm run auto-publish
```

Open http://localhost:3000/admin/

## Build

```bash
npm run build
```

## Deploy (GitHub Pages)

```bash
npm run deploy
```

## Project Notes

- Content files: `src/content/zh.json`, `src/content/en.json`
- Deploy config: `package.json` `homepage`, `predeploy`, `deploy`
